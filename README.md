# Shark Comparison Tool

A beginner Python project created while learning programming fundamentals.

The application allows the user to select two shark species and compare them based on:

- Maximum length
- Estimated maximum speed
- Distribution

## Shark species included

- Great White Shark
- Bull Shark
- Tiger Shark
- Blue Shark
- Shortfin Mako

## Python concepts used

- Dictionaries
- Lists
- For loops
- `enumerate()`
- User input
- Indexing
- `if / elif / else`
- Comparison operators
- F-strings
- Input validation

This project was created as part of my learning process in Python and Computational Thinking.

> Note: Shark speed values are approximate estimates used for educational purposes.
